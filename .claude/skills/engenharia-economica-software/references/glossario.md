# Glossário (português e inglês)

| Sigla PT | Sigla EN | Termo | Definição curta |
|---|---|---|---|
| VP | PV | Valor presente | Valor hoje de um montante futuro descontado pela taxa |
| VF | FV | Valor futuro | Valor de um montante atual capitalizado pela taxa |
| TMA | MARR | Taxa mínima de atratividade | Menor retorno aceitável para investir; taxa de desconto |
| VPL | NPV | Valor presente líquido | Soma dos fluxos descontados, incluindo o investimento |
| TIR | IRR | Taxa interna de retorno | Taxa que zera o VPL |
| TIRM | MIRR | TIR modificada | TIR com reinvestimento e financiamento a taxas explícitas |
| IL | PI | Índice de lucratividade | VP dos fluxos futuros dividido pelo investimento |
| CAUE | EUAC | Custo anual uniforme equivalente | VPL convertido em série anual; compara vidas diferentes |
| ROI | ROI | Retorno sobre o investimento | (ganho - custo) / custo |
| CapEx | CapEx | Despesa de capital | Investimento em ativos (desenvolvimento, hardware) |
| OpEx | OpEx | Despesa operacional | Custos recorrentes de operação |
| CAC | CAC | Custo de aquisição de cliente | Gasto comercial por cliente novo |
| LTV | LTV | Valor do tempo de vida do cliente | Margem esperada ao longo da relação |
| ARPA | ARPA | Receita média por conta | Receita mensal média por cliente |
| GVA | EVM | Gerenciamento de valor agregado | Integra escopo, prazo e custo |
| ONT | BAC | Orçamento no término | Orçamento total aprovado |
| VP (GVA) | PV | Valor planejado | Custo orçado do trabalho planejado até a data |
| VA | EV | Valor agregado | Custo orçado do trabalho realizado |
| CR | AC | Custo real | Custo efetivo do trabalho realizado |
| VC | CV | Variação de custo | VA - CR |
| VPr | SV | Variação de prazo | VA - VP |
| IDC | CPI | Índice de desempenho de custo | VA / CR |
| IDP | SPI | Índice de desempenho de prazo | VA / VP |
| ENT | EAC | Estimativa no término | Custo final projetado |
| EPT | ETC | Estimativa para terminar | EAC - CR |
| VNT | VAC | Variação no término | BAC - EAC |
| IDPT | TCPI | Índice de desempenho para término | Eficiência necessária no restante |
| WSJF | WSJF | Trabalho mais curto ponderado primeiro | Custo do atraso / tamanho |
| ICE | ICE | Impacto, confiança e facilidade | Produto das três notas |
| | WACC | Custo médio ponderado de capital | Média dos custos de capital próprio e de terceiros |
| LIMS | LIMS | Sistema de gestão de informações laboratoriais | Categoria de software para laboratórios |
| | Sunk cost | Custo afundado | Gasto passado e irrecuperável; não muda a decisão futura |
